Comparison with the Paper's Table 2

Test mean absolute error (MAE) is measured in uptake percentage points; lower is better. Our ± values are sample standard deviations across five runs, not confidence intervals. Table 2 reports five-run means only.

Fixed split: the same training, validation, and test samples are used in all five runs (split seed 7); only model seeds change (7-11). Varied splits: both the split and model seeds change together (7-11). Each run uses 192 training, 24 validation, and 24 test observations. All runs are retained; none were selected for closeness to the paper.

Fixed-split differences from the paper are +0.33 for RF, +0.93 for NN, and +2.22 for GBT. With varied splits, GBT and NN have similar means but appreciable variability. This does not establish statistical equivalence to the paper.

Recovery of the Missing Gene Data

CLTA, CLTB, CLTC, and PICALM were recovered from the four raw GEO microarrays cited in the paper; CAV1 and CAV2 were also re-extracted. No zeros, random values, or values estimated from a heatmap were used as substitutes.

  • OVCAR4: GSM564167
  • PANC02: GSM1406256
  • 4T1: GSM1529765
  • HDF: GSM613188

Validation against 53 existing genes across four cell types reproduced all 212 expression values in the current author repository, with a maximum absolute error of 1.15e-14, using:

expression = log2(median(gMeanSignal of matched gene spots)
                  / mean(gMeanSignal of all array spots))

Gene names were matched by case-insensitive substring; AGRIN was mapped to the alias AGRN for HDF. This preprocessing rule was inferred from verifiable data; the authors did not release the corresponding preprocessing script.

Training Settings Used in This Rerun

  • Inputs: six polymer proportions, Size, Polydispersity, six genes, and three binary attributes (cancerous, metastatic, and human). Cell identity was used only to join and track records, not as an additional feature.
  • RF: 75 trees, maximum depth 13. The unreported max_features setting was taken from the repository: sqrt.
  • GBT: 50 trees, maximum depth 5, learning rate 0.1.
  • NN: 17 → 41 ReLU → 41 ReLU → 1 linear output; RMSprop with learning rate 0.001, MSE loss, batch size 5, and 100 epochs. The optimizer and batch size came from the authors' final training code.
  • Normalization statistics were calculated from training data only. The final NN epoch was evaluated, without test-based epoch selection or prediction clipping. Published final hyperparameters were used directly; the historical tuning search was not repeated.
  • Environment: Python 3.10.18, scikit-learn 1.2.2, TensorFlow/Keras 2.10.0, NumPy 1.23.5, and SciPy 1.10.1; training used the CPU.

Unreported Details and Sensitivity Checks

The methods describe nine NN input nodes, whereas Figure 5 lists 17 features; this rerun uses 17. The paper does not specify seeds or how the five repeats were performed, so both fixed and varied splits are reported. The old supplementary-material URL returned HTTP 404 during retrieval; an alternative publisher URL returned HTTP 403.

Unreported random forest parameter

Changing max_features to 1.0 in an additional control gave a fixed-split MAE of 12.80 ± 0.58. This setting changes the numerical gap from the paper; tuning toward 13.09 alone cannot establish a successful reproduction.

Numerical stability of linear regression

The features are collinear: formulation proportions sum to a constant, and cell-related expression has only four distinct profiles. The original scikit-learn solver produces very large coefficients. The reported LM results are retained, alongside a separate stable-SVD diagnostic; its fixed-split MAE is 15.92. Library versions and feature ordering can therefore affect the rerun's numerical results.

Validation and Reproducibility Files

All 1,536 test predictions were checked against the reported MAEs. Training, validation, and test subsets were disjoint within each of the 16 recorded partitions, and all 16 NN runs completed 100 epochs. Independent runs with identical data and seeds produced identical predictions; reloading a saved NN reproduced its predictions.
